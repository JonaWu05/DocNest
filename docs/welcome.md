# 歡迎使用 Markdown 編輯器

這是一個支援即時協作的線上 Markdown 編輯器。左側是檔案樹，右側是內容區，可隨時切換閱讀與編輯。

## 開始使用

- 在左側**檔案樹**點選檔案開啟；上方搜尋框可即時過濾檔名（按 Esc 清空）。
- 右上角切換三種模式：**預覽**、**編輯**、**分割**（編輯與預覽並排）。
- 編輯後按**儲存**；也可勾選**自動儲存**讓變更自動寫入。

## 快捷鍵

| 按鍵 | 功能 |
|------|------|
| Ctrl + S | 儲存 |
| Ctrl + 1 / 2 / 3 | 切換 預覽 / 編輯 / 分割 |
| Esc | 關閉開啟中的對話框 |

## 功能一覽

- **目錄（TOC）**：依文件標題自動產生大綱，捲動時會高亮目前段落，點擊可跳轉。
- **附件**：可上傳圖片或檔案，直接拖放、貼上也行；插入後以相對連結引用。
- **分頁連結**：插入連到工作區內其他文件的連結，點擊即可站內轉跳。
- **即時協作**：可看到誰在線、誰正在看或編輯同一份文件；他人儲存時會提示載入最新版本。
- **匯出 PDF**：透過瀏覽器列印，於對話框選「另存為 PDF」。
- **深淺色主題**：右上角可切換，並會記住你的選擇。
- **行動裝置**：窄螢幕時左上角的選單鈕可滑出檔案樹。
